# 70자 이하의 간단한 제목을 사용합니다.
# 타입 단축키 + 콜론(:) 또는 세미콜론(;)만 쳐도 자동으로 전체 타입으로 변환됩니다
# (제목 맨 앞에 있을 때만, 한글 키보드에서 Shift 없는 ;도 가능)
#   f : 관심사 등록 API 추가        → feat : 관심사 등록 API 추가
#   r : 완전 탐색 -> 이분 탐색       → refactor : 완전 탐색 -> 이분 탐색
# TDD 커밋 단축키 (타입 뒤에 그냥 1만 붙이면 됨 — t1=Red, f1/x1=Green, r1=Blue):
#   t1 : 실패 테스트 추가  → test(red) : 실패 테스트 추가      (Red는 test만)
#   f1 : 기능 구현        → feat(green) : 기능 구현          (Green은 feat 또는 fix만)
#   x1 : 버그 수정        → fix(green) : 버그 수정
#   r1 : 코드 정리        → refactor(blue) : 코드 정리       (Blue는 refactor만)
# 이슈 번호는 제목 맨 끝에 대괄호로 씁니다. PR 커밋 중 한 번 이상이면 됩니다. ex) t1 : 실패 테스트 추가 [#30]
# 콜론 앞 공백은 커밋 시 자동으로 들어가니(feat: → feat :) 안 띄우고 써도 됩니다.

####################
# f(feat) : 신기능 추가
# x(fix) : 코드 및 버그 수정
# r(refactor) : 코드 리팩토링 (파일/폴더명 변경 포함)
# d(docs) : 문서 수정
# c(chore) : 설정 변경
# t(test) : 테스트 코드 추가/수정 (TDD 사이클 커밋 포함)
# b(batch) : 배치 작업 관련 변경
####################

# 템플릿 사용 방법
# 1. git add . 혹은 git add <파일명> 입력
# 2. git commit
# 3. 제목 작성
# 4. 파일 저장 후 닫기
# 5. 커밋 완료
